# 浅色液态玻璃 UI 改造设计

## 已确认方向

将现有紫黑色工作台整体替换为苹果式、克制的浅色液态玻璃视觉。保留业务功能、文案、数据与导航结构。桌面端优先，先交付本地预览，不自动推送远端。

## 当前结构

- `frontend/src/styles/variables.less`：Less 颜色、间距、圆角与阴影令牌，目前使用紫色主色和深色背景。
- `frontend/src/styles/reset.less` 与 `index.less`：全局文字、背景、焦点和基础样式。
- `frontend/src/layouts/DefaultLayout.vue`：工作台外壳与岗位、简历、分析、状态、面试导航；首页通过 immersive 标志独立显示。
- `frontend/src/components/Base*/`：共享按钮、输入框、弹窗、表格、空状态。
- `frontend/src/modules/job-search/` 与 `interview-prep/`：业务视图及部分局部硬编码深色样式。
- `frontend/src/views/HomeView.vue`：照片水波背景与唯一 Get started 按钮。

## 目标视觉

工作台采用浅灰白底色、轻微蓝色背景氛围、深色正文和蓝色操作强调。导航与浮层使用更通透的玻璃；表单、长文本和列表使用更高不透明度的阅读表面。统一细高光边缘、柔和阴影和圆润但不过度胶囊化的容器。

顶部导航为悬浮玻璃胶囊，选中项有清晰蓝色强调。玻璃材质由半透明底色、有限范围 backdrop-filter、内侧高光和边界阴影实现；不新增全屏 WebGL 或持续鼠标折射动画。实现网页端相近视觉，不承诺苹果原生材质的完全复制。

首页保留原有两张照片、随机背景、水波效果、唯一按钮及跳转行为。仅按钮适配浅色玻璃材质，确保在两张照片上都清晰。

## 目标架构与改动边界

优先在全局令牌和共享组件层定义统一材质，再适配工作台外壳及各业务视图的局部样式。模块内仍只引用本模块和共享组件、样式与工具；不新增跨模块导入。

覆盖岗位列表及审核、岗位详情、简历、分析、状态、面试总览、问题记录和现有面试准备页面；现有 todo 与未找到页面沿用统一基础视觉。清理各视图与组件的硬编码紫黑色，不用全局强制覆盖补丁隐藏旧样式。

不改后端、数据库、API、Pinia 业务行为、路由路径、业务文案或已有记录。不新增依赖、账号、主题切换器、移动端专属流程或自动部署。

## UI 契约与状态

保留加载、空状态、错误、禁用、选中及提交状态。成功、警告、错误使用可区分语义色，保留用户配置的状态颜色。输入框聚焦、键盘导航和焦点轮廓明确；模态背景与原生 select 选项适配浅色。

正文与操作文本以 WCAG AA 对比度为目标；透明材质不得降低信息可读性。缺少 backdrop-filter 时用更实的浅色底色降级；减少动态效果偏好下关闭非必要动画。保留现有窄屏可用性，但本次核心验收面向桌面。

## 执行顺序

1. 制定实施计划并创建隔离分支，保留当前未跟踪根目录锁文件。
2. 建立并验证外壳、令牌和基础组件的回归测试。
3. 实现浅色背景、玻璃导航、共享输入与操作组件。
4. 逐页适配局部面板、列表、弹窗和首页按钮。
5. 完成自动验证与桌面浏览器实测，记录统一设计规则。
6. 保留本地预览，等待用户确认；不自动合并或推送。
