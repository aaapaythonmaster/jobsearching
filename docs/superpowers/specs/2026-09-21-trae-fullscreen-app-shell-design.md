# Trae 风格全屏三栏工作台设计规范

## 目标

功能页直接进入一个桌面端应用壳层，完全采用规则的左、中、右三栏：左侧模块导航，中间主要工作区，右侧随当前工作区变化的上下文区。首页只存在于 `/`，不再在功能页上方重复渲染。

## 当前结构事实

- `frontend/src/layouts/DefaultLayout.vue` 当前同时渲染首页和工作区，并通过滚动进入工作区。
- 工作区已有 `.layout__sidebar`、`.layout__main-column`、`.layout__context-column`，但外层有固定宽度、外边距和圆角容器，不能形成 Trae 式全屏应用壳层。
- `frontend/src/components/WorkspaceContextPanel.vue` 已提供右栏空状态和插槽，但使用了圆角卡片与固定最小高度。
- 岗位、简历、分析、状态和面试路由已经存在，Pinia、API 和业务数据接口不变。

## 目标架构

`DefaultLayout` 只根据路由在首页视图和工作台壳层之间二选一：根路由渲染 `HomeView`；其他路由渲染全视口 `layout--workspace`。工作台使用 CSS Grid：`220px minmax(0, 1fr) 360px`，三列高度为 `100dvh`，列之间用 1px 分隔线，三个区域分别处理纵向滚动。

- 左栏：品牌、绿色「新建」操作、岗位/简历/面试一级导航、分析/状态/设置辅助导航。
- 中栏：紧凑工具栏、当前模块标题、路由视图；仅中栏承担主要业务操作。
- 右栏：固定顶部工具栏和上下文面板；没有选中项时使用统一空状态，已有业务页面通过插槽提供模块摘要。
- 右栏在岗位、简历、分析、状态和面试路由显示不同标题和说明；不改变现有 API 或 store。

## 视觉与交互

- 背景 `#F3F4F6`，面板白色，主文字 `#0A0B0D`，主操作 `#32F08C` 配黑色文字。
- 工作台正文采用 `Inter, "PingFang SC", sans-serif`，基准 13px；重要按钮默认 32px 高、水平内边距 12px。
- 功能页取消外层大圆角、大面积渐变和毛玻璃；内部业务卡片可保留轻量边框与 8px 圆角。
- 键盘焦点、hover、active、disabled 和 `prefers-reduced-motion` 行为保持可见且可访问。
- 桌面端覆盖 1024px、1280px、1440px；1024px 时收窄右栏，不隐藏右栏。

## 变更边界

修改布局外壳、共享上下文面板、布局测试与必要的页面容器样式；不修改后端、数据库、API、Pinia store、路由路径和首页 Ripple/背景素材。

## 验收标准

1. `/` 只显示首页；任一功能路由直接显示占满视口的三栏工作台。
2. 三栏有稳定宽度和分隔线，无外层居中卡片或上下大间距。
3. 左栏只负责导航，中栏只负责主要工作区，右栏只负责当前上下文。
4. 右栏标题和说明随路由变化；空状态文案可读。
5. 主要按钮是绿色背景、黑色文字，功能页不出现首页大标题或首页背景层。
