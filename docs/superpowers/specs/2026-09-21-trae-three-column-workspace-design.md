# Trae 风格三栏求职工作台设计规范

## 1. 目标

将进入工作台后的界面改造成桌面端工具型三栏布局，参考 Trae 的中性灰、黑色文字和绿色主操作语言。首页继续保留自然影像和 Ripple Distortion，三栏系统只应用于功能工作台。

本规范只定义桌面端视觉、布局和交互方向，不改变后端接口、数据库结构或业务数据模型。

## 2. 总体布局

```text
左侧导航        中间主工作区                         右侧上下文面板
岗位            岗位列表 / 筛选 / 新增               当前岗位详情 / 状态 / 快捷操作
简历            简历列表 / 上传 / 编辑               简历预览 / 版本信息 / 编辑入口
面试            面试项目 / 问题 / 复盘               面试进度 / 待复习问题 / AI建议
```

- 左侧固定宽度约 220px，负责一级模块导航。
- 中间区域自适应，是主要操作区域，承载列表、表单和工作流。
- 右侧固定宽度约 320–360px，根据当前模块和选中项显示上下文。
- 三栏之间使用浅色分隔线，不使用厚重阴影。
- 右侧没有选中项时显示统一空状态，不占用中间区域的操作空间。

## 3. 视觉系统

### 色彩

- 页面背景：`#F3F4F6` 或同等明度的浅灰。
- 面板背景：`#FFFFFF`。
- 主文字：近黑色；辅助文字：中性深灰。
- 主操作色：`#32F08C`，按钮文字使用黑色。
- 选中背景：低透明度绿色，不能使用高饱和整块荧光绿。
- 错误、警告、成功状态保留语义色，但必须同时配合文字。

### 形态

- 面板圆角统一为 8–12px。
- 主按钮使用紧凑矩形，不使用大胶囊按钮。
- 功能页面取消大面积毛玻璃和明显环境渐变。
- 面板使用 1px 浅灰边框；只有弹窗、浮层和右侧悬浮操作允许使用轻阴影。
- 图标使用线性 SVG，图标颜色跟随文字或状态色，不使用 emoji。

### 字体

- 工作台全部使用系统无衬线字体，黑色标题和深灰正文形成清晰层级。
- 首页品牌标题可以继续保留宋体，但不延伸到功能页。
- 页面标题、区块标题、辅助标签使用明确的字号和字重层级。

## 4. 左侧导航

- 顶部显示产品名称「求职工作台」和轻量品牌标记。
- 一级导航：岗位、简历、面试。
- 二级/辅助导航：分析、求职状态、设置。
- 当前项使用浅绿色底色、黑色文字和绿色侧边标记。
- 导航按钮满足键盘访问和可见焦点要求，最小点击区域不低于 44px。
- 底部可显示工作台状态，但不重复右侧上下文信息。

## 5. 中间主工作区

中间工作区的原则是“主任务优先”，每个模块首屏都应让用户知道当前任务和下一步动作。

### 岗位

- 顶部显示岗位标题、搜索/筛选和绿色「新增岗位」按钮。
- 列表行优先显示公司、职位、当前状态和下一步操作。
- 选中岗位后更新右侧面板，不强制离开当前列表。

### 简历

- 顶部显示简历标题、筛选和绿色「上传简历」按钮。
- 中间展示简历列表或编辑工作区。
- 选中简历后，右侧展示预览、目标方向、更新时间和编辑入口。

### 面试

- 中间展示面试项目和复盘入口。
- 问题记录、回答和复盘保持在主工作区完成。
- 右侧展示当前岗位的面试进度和待复习项。

### 分析与状态

- 分析页中间展示岗位选择和结果摘要，右侧展示风险提醒和建议动作。
- 状态页中间管理阶段列表，右侧展示当前阶段说明和岗位数量。

## 6. 右侧上下文面板

右侧面板必须随当前路由和选中项变化，不做静态装饰栏。

| 工作区 | 右侧内容 |
| --- | --- |
| 岗位 | 公司、职位、JD 摘要、薪资、当前状态、下一步操作 |
| 简历 | 简历预览、目标方向、更新时间、编辑入口 |
| 面试 | 面试轮次、待复习问题、最近复盘、回答建议 |
| 分析 | 选中岗位数、分析摘要、风险提醒、建议动作 |
| 状态 | 阶段说明、岗位数量、最近活动 |

右侧空状态统一使用：

```text
选择一项内容
这里会显示详细信息和快捷操作
```

空状态必须包含可读文本，不依赖图标或颜色表达含义。

## 7. 交互和可访问性

- 中间列表选中项后，右侧面板同步更新，保持当前滚动位置。
- 右侧主要操作使用绿色按钮，次级操作使用白底黑字边框按钮。
- 所有按钮必须有可读名称、`button` 语义和可见键盘焦点。
- 支持 `prefers-reduced-motion`；面板切换只使用轻量透明度/位移动效。
- 正文与背景对比度至少 4.5:1。
- 桌面端优先支持 1280px 和 1440px；1024px 时右侧面板允许收窄但不消失。

## 8. 实施边界

第一阶段只改动：

- `DefaultLayout` 三栏外壳和导航
- 岗位、简历、面试、分析、状态页面的主工作区分组
- 右侧上下文面板的显示结构和空状态
- 全局颜色、按钮、边框、圆角和字体 token
- 相关组件测试和桌面端验证

第一阶段不改动：

- 后端 API、数据库和迁移
- Pinia store 的数据接口
- 首页 Ripple Distortion 和自然背景
- 业务流程和数据字段

## 9. 验收标准

- 功能页在 1280px 桌面宽度下稳定显示三栏结构。
- 左侧只负责导航，中间只负责主要工作区，右侧只显示当前上下文。
- 岗位、简历、面试三种工作区的右侧内容明显不同。
- 主要按钮统一为绿色背景、黑色文字。
- 页面主体不再依赖蓝绿色渐变或大面积毛玻璃。
- 选中项、空状态、加载状态、错误状态和键盘焦点均清晰可见。
