# Calm Productivity OS 设计规范

## 1. 目标

将求职工作台统一为专业、安静、可持续使用的效率工具。首页负责建立品牌情绪，功能页负责让用户快速完成岗位、简历、分析、状态和面试任务。

本规范只定义视觉和交互方向，不改变后端接口、数据模型或业务流程。

## 2. 设计定位

- 产品类型：个人求职管理工作台
- 目标用户：需要持续管理秋招岗位、简历版本和面试准备的求职者
- 设计语言：Calm Productivity OS
- 设计变化度：5/10
- 动效强度：3–4/10
- 信息密度：5–6/10

核心原则：

1. 首页可以有情绪，功能页必须有秩序。
2. 玻璃材质用于品牌入口和少量层级容器，不覆盖所有卡片。
3. 每个页面都要让用户看见当前状态和下一步行动。
4. 蓝绿色建立品牌识别，状态色只表达语义，不作为装饰。

## 3. 全局视觉系统

### 色彩

- 页面背景：浅蓝灰或近白色，避免纯白刺眼。
- 主色：深海蓝/青蓝，用于主按钮、链接、选中状态和焦点环。
- 辅助色：低饱和绿色，仅用于完成、通过和已就绪状态。
- 警告色：琥珀色；危险色：低饱和红色。
- 正文使用深蓝灰，不使用纯黑。

现有蓝绿色 token 可以继续作为基础，但需要保持整站单一主色体系，避免页面之间出现不同风格的蓝色或渐变。

### 材质与边界

- 工作台主背景使用平面色或极轻的环境渐变。
- 功能页优先使用细边框、分割线和留白建立层级。
- 阴影使用低对比、偏蓝灰的软阴影。
- 卡片圆角统一为中等圆角；按钮可使用略小圆角，不混用尖角、胶囊和大圆角。
- 毛玻璃只保留给侧边栏、弹窗和需要浮起的局部容器。

### 字体

- 功能页使用系统无衬线字体，保证表格、表单和状态信息可扫描。
- 首页主标题可以继续使用宋体作为品牌情绪点。
- 正文基准字号不低于 14px，行高保持 1.5 左右。
- 页面标题、区块标题和辅助文字建立明确的三级层级。

## 4. 工作台外壳

- 左侧固定导航，桌面端宽度约 232–256px。
- 导航包含品牌、当前模块、状态提示和必要的辅助入口。
- 当前项使用浅色背景、主色文字和细边框，不依赖强阴影。
- 主内容区保持较宽留白，最大宽度约 1180–1240px。
- 顶部显示当前模块名称、上下文信息和必要的操作，不堆叠装饰。
- 首页进入工作台后，滚动位置和焦点状态要连续，避免突然跳转。

## 5. 页面方向

### 岗位页

- 默认展示岗位列表和状态筛选。
- 每个岗位首先显示公司、职位、当前状态和下一步行动。
- 重要日期、面试安排和待处理项使用轻量状态标签。
- 新建岗位是主操作，筛选和批量操作作为次级操作。

### 简历页

- 采用“左侧简历列表 + 右侧详情/编辑区”的工作区结构。
- 列表显示名称、目标方向、更新时间和来源文件。
- 右侧提供文本修正、备注和保存状态。
- 上传入口保持明显，但不占据整个页面的视觉中心。
- 空状态需要说明下一步：上传 Word/PDF 或创建第一份基础简历。

### 分析页

- 将分析结果分成“发现的问题、建议动作、已处理项”。
- 结果优先使用摘要和可执行建议，不直接堆叠长文本。
- 复杂内容采用渐进展开，避免首次加载时信息过载。

### 状态页

- 使用阶段分组或轻量看板表达投递进展。
- 状态颜色必须同时配合文字，不能只靠颜色传达含义。
- 每个阶段显示数量、最近活动和下一步动作。

### 面试页

- 使用阶段时间线、项目卡片和待复习问题组织内容。
- 突出下一场面试、待练习问题和最近复盘。
- 面试记录保留情绪温度，但操作结构仍以任务和进度为主。

## 6. 动效与可访问性

- 页面切换和列表进入使用 150–300ms 的轻量过渡。
- 重要状态变化提供明确的文字反馈和加载状态。
- 支持 `prefers-reduced-motion`，关闭非必要动画。
- 所有可交互元素保留键盘焦点样式。
- 文本与背景满足至少 4.5:1 对比度。
- 图标使用 SVG，并配合文字或可访问标签，不使用 emoji 作为功能图标。

## 7. 实施边界

第一阶段只统一：

- 全局 token、背景、字体和圆角
- DefaultLayout 导航和工作台外壳
- 岗位页、简历页、分析页、状态页、面试页的层级和空状态
- 页面级动效与焦点行为

第一阶段不新增业务能力、不修改 API、不改变数据库结构、不引入新的 UI 框架。

## 8. 验收标准

- 首页和功能页明显属于同一产品，但视觉密度和动效强度有明确区分。
- 用户进入任一功能页后，能在首屏识别当前模块、当前状态和主要下一步。
- 主要页面不依赖大量卡片或强阴影建立层级。
- 简历、岗位、状态和面试页面共享同一套颜色、间距、圆角和交互状态。
- 桌面端 1024px、1280px 和 1440px 宽度下无横向溢出。
- 键盘操作、加载、空状态、错误状态和减少动效模式均可用。
